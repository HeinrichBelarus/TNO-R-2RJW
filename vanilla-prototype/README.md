# TNO:R Vanilla Prototype

Локальный тестовый мод для ванильной HOI4 Operation Postern 1.19.5. Есть русская и английская локализация.

## Установка в Windows

1. Скопируйте папку `tnor_vanilla_prototype` и файл `tnor_vanilla_prototype.mod` в `Documents\Paradox Interactive\Hearts of Iron IV\mod`. Если Windows перенаправляет «Документы» в OneDrive, используйте активную папку «Документы».
2. Включите **TNO:R — Vanilla Prototype** в отдельном наборе модов лаунчера и начните новую кампанию 1936 года. Для этой проверки в наборе достаточно одного прототипа.

## Проверка

1. Начните за Германию. Проверьте портрет действующего лидера и решение «Учредить независимый Судетенланд» в категории «Судетский вопрос».
2. Получите северные Судеты (область 69) через ванильный контент или, для короткой проверки на отдельном тестовом сохранении, выполните в консоли `setowner GER 69` и `setcontroller GER 69`. Примените решение. У Германии должно исчезнуть владение областью 69, а на карте должен появиться независимый **SUDETENLAND** с тегом `SDT`.
3. Выполните `tag SDT`. Проверьте, что два стартовых фокуса взаимоисключающие. Завершите «Курс на восток», затем «Подготовить железные дороги». В решениях запустите обследование сети. Через 14 дней появится событие с выбором бонуса на 90 дней. Чтобы проверить западный вариант, загрузите сохранение до выбора курса.
4. В дипломатии Бразилии проверьте **TEST UNION** с Бразилией и Аргентиной. Альянс и портрет задаются при старте новой кампании.

Скрипты, локализация и графические файлы проверены статически. Проверка в запущенной игре ожидает установку HOI4.

Если категория не появилась, на вкладке Home лаунчера проверьте выбранный набор. Если портрет Германии и TEST UNION тоже отсутствуют, проверьте, что папка мода содержит `common` прямо внутри и что рядом с папкой лежит файл `tnor_vanilla_prototype.mod`. Свежий `logs/error.log` из папки Hearts of Iron IV поможет проверить ошибки загрузки и скриптов.
